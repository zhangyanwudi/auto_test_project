# AI Command List Skill

## 🔒 上下文隔离机制（通用 — 适用于所有 @ 指令）

**以 `@` 开头的任何指令消息都会自动切断历史上下文，这是后端实现的通用规则，不限于特定指令：**

- 后端检测到 `@` 前缀 → 仅发送 **system prompt + 当前消息**（含上传文件解析块）
- 不携带任何历史对话记录，确保每次 `@` 指令都是干净的独立会话
- **好处**：防止上下文过长导致 AI 回复超时或失败；减少无关 token 消耗
- **后续消息**（如回复行号 "20"）不以 `@` 开头 → 正常携带完整历史上下文
- **适用范围**：当前及未来新增的**所有** `@` 前缀指令（`@command`、`@热更测试`、`@hot-update-test`……）

> 📌 添加新指令时无需额外配置上下文隔离 — 只要以 `@` 开头即自动生效。

> 📌 这意味着：即使在同一对话中连续多次发送 `@` 命令，每次都是全新的开始，互不干扰。

## ⛔ 触发条件（严格限制）

**仅在用户消息以以下前缀开头时激活：**
- `@command`、`@commands`、`@命令` → 列出所有命令
- `@hot-update-test` → 执行热更测试

**以下情况绝对不要激活：**
- 用户消息中普通提及「命令」「command」但**没有 `@` 前缀**
- 用户正在讨论技术问题、排查 bug、查看日志时
- 任何不以 `@` 开头的消息

## 行为逻辑

### 1. 列出所有命令（`@command` / `@commands` / `@命令`）

当用户输入 `@command`、`@commands`、`@命令`（或仅输入 `@` 后跟空格/回车），**必须严格输出以下内容，一字不改，不添加任何额外文字或解释**：

📋 可用命令列表：

【测试】
  @hot-update-test / @热更测试  — AB 实验热更调参自动化配置比对测试
  @case-explore / @生成巡检规范  — 生成网页巡检规范并试运行

【系统】
  @command / @commands / @命令  — 显示此命令列表

---

💡 使用方法：输入 @<命令Key> 或 @<中文名> 即可执行
💡 添加新命令：编辑 .claude/skills/ai-command-list.md 的「命令注册表」

### 2. 执行命令（`@<command-key>`）

当用户输入以 `@<command-key>` 开头时（如 `@hot-update-test`）：

1. **精确匹配 `@` 前缀** — 只有消息以 `@` 开头才处理，普通对话中的 `@` 不在此列
2. **查找命令** — 在「命令注册表」中查找匹配的 `命令 Key`
3. **找到匹配** → 读取对应的参考文件（`.claude/references/<skill-file>.md`），严格按照其中的流程执行
4. **未找到匹配** → 返回提示并列出所有可用命令：
   ```
   ❌ 未找到命令: @<command-key>
   
   可用的命令有：
   - @hot-update-test — 热更测试
   - @command — 命令列表
   
   输入 @command 查看完整命令列表
   ```

### 3. 模糊匹配与纠错

如果用户输入的命令 Key 与注册表中的命令相似但不完全匹配：

1. 尝试精确匹配
2. 如果精确匹配失败，尝试模糊匹配（忽略大小写、连字符/下划线互换）
3. 如果找到唯一匹配，提示用户并确认是否执行
4. 如果找到多个匹配，列出候选项让用户选择

## 添加新命令指南

如需添加新命令，在本文件的「命令注册表」表格中新增一行：

```markdown
| `my-new-command` | 我的新命令 | `my-new-command` | 分类名 | 命令的简要说明 |
```

同时需要：

1. **创建对应参考文件**：`.claude/<command-key>.md`
2. **更新分类表**：如果使用了新的分类，在「命令分类」中添加
3. **确保参考文件规范**：
   - 定义触发条件
   - 说明执行流程
   - 列出输入输出规范

## 注意事项

1. **命令 Key 命名规范**：使用小写字母 + 连字符（kebab-case），如 `hot-update-test`
2. **参考文件路径**：`.claude/<command-key>.md`（放在 .claude 根目录，不会被系统自动加载到上下文中）
3. **唯一性**：每个命令 Key 必须唯一，不可重复注册
4. **参数传递**：命令后的附加内容会作为参数传递给目标命令
5. **链式调用避免**：如果被调用命令内部也使用了 `ai-command-list`，需避免无限循环
